## 🚧 Status do Desenvolvimento


O projeto **BlueGuard** encontra-se em fase inicial de desenvolvimento
(MVP 1 – Reconhecimento).


As funcionalidades atuais estão focadas em:
- Descoberta de ativos autorizados
- Validação de hosts ativos
- Identificação de portas e serviços


---


## 🎯 Escopo do MVP Atual


**MVP 1 – Reconhecimento**
- Subdomínios (subfinder)
- Hosts ativos (httpx)
- Portas e serviços (nmap)
- Execução via CLI
- Saída em arquivos de texto


---


## ⚠️ Uso Autorizado e LGPD


O BlueGuard deve ser utilizado **exclusivamente em ativos e ambientes
para os quais o usuário possua autorização formal**.


A ferramenta segue os princípios da **LGPD**, especialmente:
- Segurança
- Prevenção
- Minimização de dados
- Responsabilização


O uso indevido é de inteira responsabilidade do operador.
